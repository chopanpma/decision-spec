# F11 review — `[runners]` per-tool overrides, wired

Reviewer: main-orchestrator. Verdict: **approved** (board row → done).

## User trigger (2026-10-02)

"all tests were skipped because of not toolset installed": the user's
`python3` has no pytest, and run_adapters hardcoded `python3 -m pytest`, so
every real layer SKIPPED on a healthy port. Orchestrator reproduced two
distinct failures: (a) probe fails → layer skipped (user's case); (b) python3
absent entirely → spawn error propagated through `?` and aborted `decispec
test` with exit 2 "os error 2" (verified with a stripped PATH).

## Fix (coder: agent-1)

- `[runners]` table parsed (String→String) into `Config.runners`; missing
  table → empty → hardcoded defaults. Keys: pytest (full command override),
  playwright (command), cucumber/karate/conftest/import-linter/
  dependency-cruiser (program name). Probe AND run use the override;
  whitespace-split, first token = program, root-relative paths resolve via
  run_cmd's child cwd.
- Spawn errors no longer abort: probe failure → Skipped("toolchain not
  installed (<command>)"); run-phase failure → Failed with the os error as
  reason. `decispec test` always completes and writes the manifest.
- README's `[runners]` section was an ambiguous comment block; replaced with
  the implemented key list + semantics (13 lines).

## Verified by reviewer

- `cargo test`: 127 passed / 0 failed (was 124; +3 cli tests: runners parse,
  fake-executable override for probe+run, missing-binary skips quietly with
  exit 0). `cargo clippy --all-targets`: 0 warnings. Diff scope: cli/main.rs
  + README.md only.
- Rebuilt the debug binary, pinned tvgo's decispec.toml:
  `pytest = "backend/.venv/bin/python -m pytest"`.
- End-to-end under a stripped PATH (no Homebrew python3, no pytest on PATH —
  the user's environment simulated): `pytest [unit]: ran`, gate verdict PASS
  (9 passed, 1 skipped), exit 0. Previously this exact environment either
  skipped the unit layer or exited 2.

## Downstream

tvgo's port no longer depends on the developer's PATH. Other projects get the
same one-line pin. F10 (binary-level integration tests) would have caught
