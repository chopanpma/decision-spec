# Review F16 — `decispec mcp` (MCP server over stdio) — reviewer: main-orchestrator (author: coder agent-1)

Verdict: **APPROVE**

## What shipped

New pure crate `decispec-mcp` + `decispec mcp` subcommand: MCP over stdio
(NDJSON JSON-RPC 2.0; initialize/ping/tools/list/tools/call; -32601/-32700;
notifications answered with silence). Six tools: `project_info`,
`extract_project`, `validate_spec` (parse+validate a proposed spec text with
file:line diagnostics, filesystem untouched — the porting tool),
`check_workspace`, `workspace_overview` (the porting work queue: decisions
without requirements, requirements without scenarios, superseded
self-references from the F15 placeholder), `gate_status`. Pure dispatcher
(`handle_message(&mut Session, &str) -> Option<String>`) carries all logic;
thin `serve`/`serve_io` stdio loop in cli. 8 new tests (7 mcp + 1 cli);
workspace at **114 passed / 0 failed**, clippy clean.

## Findings

None blocking. Documented judgment calls (all sound): `gate_status` parses
report.json as raw `Value` (GateReport is Serialize-only; mcp not depending
on gate keeps the crate graph clean); `workspace_overview` returns
diagnostics alongside gaps instead of failing; in-process stdio test
skipped in favor of `serve_io` with a Cursor (the claim explicitly allowed
this; a real-subprocess MCP test belongs to F10's integration suite).

## Recommendations (forward-looking, non-blocking)

1. **Lift shared fs helpers into a lib crate.** `find_project_root` and the
   tolerant `decispec.toml` reader now exist in both cli (main.rs) and mcp —
   documented duplication, but the third copy is the bug. Small follow-up
   task (new `fs` lib or into `ir`): cli and mcp both depend on it.
2. **Keep the boundary: validate, never apply.** MCP deliberately exposes
   no write tools — agents propose, humans apply. Hold that line; if a
   future "agent applies spec edits" need arises, it deserves its own
   design pass (and probably a `--dry-run`/`--diff` CLI mode first).
3. **MCP resources (post-MVP):** exposing `specs/*.spec` contents as MCP
   resources would save agents a file-read round trip; tools already cover
   porting, so this is convenience, not gap.
