# Review F15 — `decispec extract` ADR ingestion — reviewer: main-orchestrator (author: coder agent-1)

Verdict: **APPROVE** (one ruling round — see below)

## What shipped

`decispec extract` now recovers **decisions**, not just structure: markdown
ADRs (MADR and adr-tools styles, in `adr/`, `decisions/`, `docs/adr/`,
`docs/decisions/`, case-insensitive, recursive) become `decision` blocks in
the draft — id `ADR-<n>` from the filename number or a scrubbed slug, title
from the first `#` heading, status mapped (deprecated→superseded; missing→
proposed + warning), context/consequences flattened to the DSL's single-line
strings (≤500 chars). Rendered before the `model` block with `# Source:`
comments; scaffold exclusions apply to ADR scanning; ids share the container
collision set. 8 new tests (7 lib + 1 cli); workspace at **106 passed /
0 failed**, clippy clean.

## Findings

1. **Deviation, resolved (ruling round):** the claim's "map deprecated→
   superseded" collides with the validator (`superseded` requires
   `superseded_by`, which is never determinable from an ADR). Author proposed
   a self-reference placeholder; reviewer accepted the policy and required an
   in-draft `# TODO` explaining it — landed. Rationale for accepting: the
   alternatives invent facts (mapping to `rejected` falsifies history) or
   require parse-crate changes outside F15 scope; gate semantics for
   superseded (warnings, not failures) fit a deprecated ADR, and the TODO
   routes the human to the one edit that fixes it.
2. Process note (no action): the claim's collision-fixture intent needed
   re-derivation — container ids are dash-free after `sanitize` while
   `ADR-0001` keeps its dash, so the families can only collide via slug
   equality; the author caught this in the red phase and pinned the real
   case. Good TDD hygiene.

## Recommendations (forward-looking, non-blocking)

1. **Real successors when written:** many teams write
   `Status: superseded by ADR-0007` in the ADR itself. A small regex on the
   status line would set `superseded_by` properly and drop the self-reference
   — high value, ~10 lines. Candidate for a future F16.
2. **Agent-layer handoff is documented:** `docs/PORTING.md` (orchestrator)
   defines how agents turn ingested ADR-decisions into requirements/scenarios
   — the piece extraction deliberately never attempts.
3. Consider an `extract --check` drift mode (same recommendation carried
   from F8's review — now applies to ADRs too: warn when ADR docs and the
   committed decisions diverge).
