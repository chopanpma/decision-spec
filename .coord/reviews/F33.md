## Recommendations

- **Record accept/decline for each finding in `.coord/claims/F33.md`** (per
  docs/REVIEW.md).
- **Kill the hand-audit permanently.** F29, F31's review, and F33 each
  re-invented the same "list cargo tests ↔ list `_delegate` calls" comparison.
  A 20-line workspace check (or a glue self-test iterating `cargo test
  -- --list` per package and diffing against the delegation table) would make
  "every test pinned exactly once" a `cargo test`-enforced invariant instead
  of a per-task ceremony. Natural home: a new board row, not this one.
- No spec-design changes recommended, because the split chosen here — tui-crate
  behavior in its own `060-tui.spec`, cli-seam behavior in `040-commands.spec`
  under CMD-007/008, mirroring the crate boundary AGENTS.md §3 draws — is the
  right seam, and it keeps F33's specs orthogonal to F32's in-flight code
  review.
