# Claim F44 — Portable specs: extract `--to` an external store + `init --from` (spec-only)

- **Task summary:** User request (2026-10-22): "a functionality to extract
  specs from a repo, and save them outside the repo with a parameter, so the
  specs for the projects are stored apart and can be used to create a project
  from the specs." This claim lands the SPEC ONLY (spec-first, F37 pattern):
  two `status: proposed` decisions (PORT-001, PORT-002) in a new
  `specs/080-portable.spec` (prefix PORT). Implementation (F45) wires
  `--to <dir>` on `decispec extract` and `--from <paths>` on `decispec init`
  in cli, flips the spec to accepted, pins, greens the gate.
  Operationally, decision-spec itself was registered in the TUI registry
  (`decispec tui --register`, name `spec-decision-log`) — not a board task.
- **Agent:** kimi-agent, 2026-10-22.
- **Files in scope (exact):**
  - `specs/080-portable.spec` (new)
  - `.coord/BOARD.md` (F44 row only), this claim file
- **Must not touch:** every other file — no crates, no `tests/glue/`, no
  `tests/generated/**` (gen deliberately not run — the 6 new scenario rows
  land with F45), no README/docs (orchestrator-owned; proposed doc updates
  recorded below), no other spec file.
- **Test plan:** Spec-only → no new cargo tests (TDD applies to behavior
  changes; this authors the design artifact). Validation: `decispec check`
  and `check --strict` exit 0 on the new file. `decispec gate` is EXPECTED
  RED on the 6 new rows (no glue delegates yet — the spec-first state the
  quickstart documents); F45 flips them green.
- **Design decisions fixed in the spec:**
  - `--to <dir>` writes `<dir>/<dirname>.spec` (the analyzed project's
    directory name — extract targets foreign repos that may lack a
    decispec.toml project name); never writes into the analyzed repo's own
    specs/ tree; existing target = exit 2 with the file untouched (extends
    CMD-003's overwrite refusal); `--to` + `--stdout` together = exit 2.
  - `--from <paths>` accepts .spec files and directories (direct `*.spec`
    children, one level); scaffolds decispec.toml + tests/glue/ + specs/ in
    the current directory; refuses a non-empty specs/ (exit 2, no clobber);
    validates the copied specs as a workspace BEFORE writing the scaffold —
    broken specs = exit 2 with file:line diagnostics, no half-written
    project; glue starts empty (gate red until glue lands, per the
    quickstart's spec-first flow).
- **Status:** landed 2026-10-22, pending review.
