## Design

- Glob: `*` = any run of characters, anchored, multiple stars allowed
  (classic segment walk); no `*` → exact equality, preserving the current
  resolution path (decision → req/scen/invariant/policy → parent).
- Pattern mode prints `ID (status) title` per matching DECISION, sorted by
  id; matches nothing → same finding message class as unknown id (exit 1).
- `--status` filters both modes uniformly (exact id with mismatched status
  = no match, exit 1). Unknown status string → exit 2 via error path (same
  as gate's F39 flag).
