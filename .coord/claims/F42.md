# F42 — TUI file picker: type-to-filter via `/`

## Task summary

Last item of the user-approved console queue (2026-10-20): the spec-file
picker is arrow-only; with many specs, add filtering. Design chosen after
surveying the keymap: `/` enters filter mode (idiomatic for this
vim-keyed TUI: `e`/`n`/`p`/`q` are all command letters), typed characters
narrow the list case-insensitively by substring, Backspace edits, Esc
clears the filter and leaves filter mode, a second Esc closes the picker.
`n` keeps opening naming — no F36 pin moves.

## Design

- Picking keys while `filtering`: Char appends (incl. `/`), Backspace pops,
  Esc clears filter + exits filter mode, Up/Down navigate the filtered list
  (pick_idx resets to 0 on any filter edit), Enter opens the highlighted
  match.
- Picking keys while not `filtering`: `/` enters filter mode; `n`, nav,
  Enter, Esc behave exactly as today (characterization).
- Filter is empty and `filtering == false` ⇔ pre-F42 behavior, byte for
  byte.
