## Design

- `gate::Filter { prefixes: Vec<String>, status: Option<Status>,
  only_failing: bool, only_uncovered: bool }` + pure row predicate; CLI
  parses `--prefix CMD,DSL` (comma separated), `--status accepted`,
  `--only-failing`, `--only-uncovered`.
- **Invariants pinned by spec:** filters never change the verdict or the
  exit code (0/1/2 contract untouched); `.decispec/report.json` written to
  disk is always the unfiltered report; `--json` prints the filtered view
  but the on-disk report stays full; a filter matching nothing prints a
  clear "0 rows match" line (exit code still follows the real verdict).
