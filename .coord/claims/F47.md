## Design notes

- JunitCase gains `skipped: bool`; `message` doubles as failure-or-skip
  message (field is internal to gate).
- Row rule: failed > all-skipped > pass. Matched cases all skipped → SKIPPED
  via the existing `skipped_outcome` (so strict escalation is shared, not a
  second policy). Suite fallback: all cases skipped → SKIPPED; mixed → Pass
  with "k passed, m skipped" detail.
- Allowlist entry: `[[skips]] toml table { decision, item, reason,
  requirement? }`; requirement omitted = match any requirement of that
  decision for that item. Listed skipped rows stay SKIPPED under strict
  (detail names the allowlist + reason); every other skip escalates as today.
  Entries matching zero skipped rows → report warning (ratchet drift).
  Missing/unparseable file → exit 2 (could not complete).
- Exit-code contract unchanged (0/1/2); GateReport/Counts shapes unchanged
  (tui/mcp/store readers unaffected).

## Change summary

- `gate`: `JunitCase` gains `skipped` (parse_junit reads `<skipped>`; `message`
  doubles as failure-or-skip message). New `matched_outcome` helper: failed >
  all-skipped > pass (mixed passes report "k passed, m skipped"). JUnit-evidenced
  skips route through the existing `skipped_outcome` seam, so `--strict-skipped`
  escalates them exactly like toolchain skips; suite-level fallback with all
  cases skipped now reads SKIPPED instead of "N passed". New `SkipAllowance`
  type + `parse_allowlist` (toml 0.8, new workspace dep): `[[skips]]` tables
  (decision, item, reason; optional requirement). Allowance relieves a matched
  skipped row from strict escalation (detail names the reason); entries that
  matched no skip warn as stale; allowance never touches FAIL/UNCOVERED rows.
- `codegen`: e2e stubs emit `test.fixme(...)` instead of an empty-bodied
  `test(...)` — Playwright reports `<skipped>`, closing the false-green hole
  (86 rows pre-TASH-515 in tvgo). `playwright_spec_shape_is_pinned` and
  `contract_e2e_infra_fitness_artifacts` re-pinned to the fixme byte shape.
- `cli`: gate gains `--allow-skips <PATH>`; missing/unparseable file → exit 2
  via CliError::Msg; plumbed into `GateInput.allow_skips`. cmd_gate signature
  + all call sites updated.
- Specs: GATE-008 + GATE-009 (accepted, 7 scenarios) in specs/010-gate.spec;
  GEN-003 gains `playwright_stub_marks_fixme_not_silent_pass` (context amended).
- Glue: +8 fns (5 gate, 2 cli --bins, 1 codegen); docstring count 266 → 276.
- Docs: README gate-semantics section (`<skipped>` mapping, strict escalation
