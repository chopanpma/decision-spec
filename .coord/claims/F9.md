## Task summary

`codegen::depcruise` emitted, for `rel api -> auth`, a rule whose `from` is the
rel's FROM side and `to` the TO side, i.e. it forbade **api → auth** — the very
direction the spec's rel allows and the opposite of README:187 ("forbids b → a").
dependency-cruiser's `from` is the *dependent* module, so the generated config
rejected the allowed imports and permitted the forbidden ones.

Pilot evidence (tvgo, 2026-10-02) added a second, blocking bug: depcruise 18.5.0
**rejects the generated file outright** — `rule ... has an unsafe regular
expression. Bailing out` — because the path regexes
`(^|[/\\])backend_app([/\\]|$)` trip its safe-regex check. A third pilot
finding: depcruise 18 cruises **0 modules** when handed directories as args.

Both bugs must be fixed before any project can adopt the generated config.
